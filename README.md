# E-commerce Platform

A full-stack learning project for building a secure online storefront with a product catalogue, customer accounts, cart, checkout flow, and administrative product/order tools. Checkout will remain a clearly labeled demo flow unless a payment provider is deliberately configured; the application must never store card details.

## Planned features

- Responsive catalogue with search, category filters, sorting, and pagination.
- Product details and cart quantity management.
- Registration and login with hashed passwords and protected customer/admin routes.
- Admin tools for product CRUD and order management.
- Validated demo checkout, loading/error/empty states, and API error handling.
- Documented API, environment configuration, tests, and genuine screenshot instructions.

## Technology stack

- Frontend: React, TypeScript, Vite
- Backend: Node.js, Express.js, TypeScript
- Database: MongoDB with Mongoose

## Local development

Setup commands, environment variables, API routes, and test instructions will be added with the implementation. No payment processing or deployment is currently configured.
